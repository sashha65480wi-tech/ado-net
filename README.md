# Домашняя работа по ADO.NET: приложение с PostgreSQL

Проект переделан из исходного Python/Flask-примера на C# и ASP.NET Core. Доступ к PostgreSQL выполняется через ADO.NET API провайдера Npgsql.

## Что демонстрирует проект
- `NpgsqlConnection` — подключение к базе данных.
- `NpgsqlCommand` — выполнение SQL-запросов.
- `ExecuteNonQueryAsync` — выполнение команды создания таблицы.
- `ExecuteScalarAsync` — получение одного значения (ID и число записей).
- `ExecuteReaderAsync` — чтение нескольких строк.
- `Parameters.AddWithValue` — параметризованный SQL-запрос.
- `await using` — освобождение соединений, команд и reader.

## Запуск
Нужен установленный Docker Desktop или Docker Engine с Compose.

Из папки проекта выполните:

```bash
docker compose up --build -d
```

Проверьте в браузере:
- http://localhost:8089/ — записывает визит и показывает общее количество.
- http://localhost:8089/visits — показывает последние 20 визитов.
- http://localhost:8089/health — проверяет подключение к PostgreSQL.

Остановка:

```bash
docker compose down
```

Остановка с удалением данных базы:

```bash
docker compose down -v
```

Последняя команда удаляет том с данными. Используйте её только если данные не нужны.

## Краткое описание для защиты
Приложение написано на C# с использованием ASP.NET Core. Для взаимодействия с PostgreSQL используется ADO.NET через провайдер Npgsql. При открытии главного маршрута приложение добавляет запись в таблицу `visits`, получает её идентификатор и выполняет `COUNT(*)`. Маршрут `/visits` читает записи с помощью `NpgsqlDataReader`, а `/health` проверяет соединение. Параметр `@path` передаётся отдельно от SQL-команды, что помогает защититься от SQL-инъекций.
