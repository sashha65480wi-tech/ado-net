# ADO.NET — изучение дисциплины

Данный репозиторий создан для изучения дисциплины **ADO.NET** и практического освоения технологии доступа к базам данных в экосистеме .NET.

## Цель проекта

Получить практические навыки разработки приложений на C# с использованием ADO.NET, научиться подключаться к базам данных, выполнять SQL-запросы и обрабатывать полученные данные.

## Основные темы

- Основы ADO.NET и взаимодействие с базами данных.
- Подключение к СУБД с использованием `DbConnection` и `NpgsqlConnection`.
- Выполнение SQL-запросов с помощью `DbCommand` и `NpgsqlCommand`.
- Чтение данных через `DataReader`.
- Добавление, изменение и удаление записей.
- Использование параметризованных SQL-запросов.
- Обработка ошибок и управление подключениями.
- Практическая работа с PostgreSQL.
- Использование Docker для запуска учебных приложений и баз данных.

## Технологии

- C#
- .NET / ASP.NET Core
- ADO.NET
- PostgreSQL
- Npgsql
- SQL
- Docker и Docker Compose
- Git и GitHub

## Структура репозитория

В репозитории размещаются практические и домашние задания, примеры кода, учебные проекты и материалы, созданные в процессе изучения дисциплины.

## Результат

Репозиторий служит учебным портфолио, отражающим процесс изучения ADO.NET, развитие навыков работы с базами данных и применение полученных знаний при разработке приложений на C#.
