Документация проекта «Автозапчасти»
1. Описание проекта
Проект «Автозапчасти» представляет собой веб-приложение для работы с
информацией об автозапчастях. Приложение подключается к базе данных
PostgreSQL и предоставляет пользователю возможность просматривать список
запчастей и находить нужные записи с помощью поиска.

Цель проекта --- разработать простое приложение, демонстрирующее
взаимодействие веб-сайта с базой данных.
2. Используемые технологии
В проекте используются:
- C# и платформа .NET;
- ASP.NET Core MVC;
- PostgreSQL;
- pgAdmin 4 для управления базой данных;
- Npgsql для подключения приложения к PostgreSQL;
- HTML и Razor для отображения веб-страниц.
3. Работа приложения
При запуске приложение подключается к базе данных PostgreSQL и получает
информацию о запчастях. На странице сайта отображается список записей и
поле поиска.

Пользователь может искать запчасти по названию или артикулу. Результаты
поиска отображаются на странице сайта. Если поисковая строка пустая,
отображается общий список запчастей.
4. База данных
Для хранения информации используется база данных PostgreSQL.

Название базы данных: autoparts_search
Основная таблица: parts

В таблице хранятся сведения об автозапчастях. База данных создаётся и
просматривается с помощью pgAdmin 4.
