# Самостоятельный проект — задание №1 «Поиск автозапчастей»

Готовый учебный проект ASP.NET Core MVC (.NET 8) + PostgreSQL + ADO.NET через Npgsql.

## Что уже сделано в проекте
- Модель `Part`.
- `DbHelper` с подключением к PostgreSQL и методом `SearchParts(string? query)`.
- Поиск по `name` и `article` с помощью `ILIKE`.
- Параметризованный `@q` и `AddWithValue`; пользовательский ввод не склеивается с SQL.
- Пустой запрос возвращает все записи.
- MVC-контроллер с GET-actions `Index` и `Search`.
- Страница с поисковой строкой, таблицей, количеством найденных записей и сообщением, если совпадений нет.
- Автоматическое создание таблицы при запуске, если её ещё нет, и добавление тестовых записей в пустую таблицу.

## Единственная работа в pgAdmin

### А. Создать базу
1. Запустите pgAdmin 4 и подключитесь к серверу PostgreSQL.
2. Откройте `Servers → PostgreSQL → Databases`.
3. Нажмите правой кнопкой по `Databases` → `Create → Database`.
4. Имя базы: `autoparts_search`; владелец: `postgres`; нажмите Save.

Либо откройте Query Tool на базе `postgres` и выполните содержимое `database/01_create_database.sql`.

### Б. Проверить таблицу и тестовые данные
Приложение само создаст `parts` при первом запуске. Если хотите создать таблицу вручную, откройте Query Tool именно у базы `autoparts_search` и выполните `database/02_create_parts_table.sql`. Это необязательно.

## Один раз указать пароль PostgreSQL
Откройте `appsettings.json` и замените только `CHANGE_ME` на пароль, который вы задали при установке PostgreSQL:
`Host=localhost;Port=5432;Database=autoparts_search;Username=postgres;Password=ВАШ_ПАРОЛЬ`

Пароль не нужно отправлять мне. Не публикуйте его в открытом репозитории.

## Запуск в Visual Studio 2022
1. Установите .NET 8 SDK (если ещё не установлен).
2. Распакуйте архив.
3. Откройте `FirstTask_AutoParts_Search.csproj` через Visual Studio.
4. Дождитесь восстановления NuGet-пакетов (Npgsql указан в `.csproj`). Если не восстановились: Build → Restore NuGet Packages.
5. Убедитесь, что служба PostgreSQL запущена и база `autoparts_search` создана.
6. Нажмите F5 или Ctrl+F5. Профиль HTTP открывает `http://localhost:5080`.

## Запуск из терминала
В папке с `.csproj`:
```bash
dotnet restore
dotnet run
```
Откройте URL, который выведет терминал.

## Проверка задания
- Введите `фильтр` — должны найтись масляный и воздушный фильтры.
- Введите `of-1001` или `OF-1001` — должна найтись одна запись, регистр не важен.
- Оставьте строку пустой и нажмите «Показать все» — отобразятся все записи.
- Введите заведомо отсутствующий текст — появится сообщение, что записи не найдены.

## Если не подключается
- `password authentication failed` — проверьте пароль в `appsettings.json`.
- `Connection refused` — проверьте, запущена ли служба PostgreSQL и порт `5432`.
- `database does not exist` — проверьте, что база называется точно `autoparts_search`.
- `Npgsql` не найден — выполните восстановление NuGet-пакетов.

Примечание: проект рассчитан на чистую базу с полями `id`, `name`, `article`, `price`, `stock`. Встроенное создание таблицы не изменяет уже существующую таблицу с несовместимой схемой.
